# Savings Calculator

A financial planning tool for estimating future savings.

## Features

- Initial savings
- Monthly contribution
- Total savings estimate

## How to Use

Enter current savings, monthly savings and duration.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
